# 会议界面模拟器（网页版）

一个可在电脑浏览器中打开的会议界面模拟页面，用于界面演示、排版和截图。项目是非官方模拟器，不会加入真实会议，也不会修改电脑的系统时间。

## 快速开始

1. 下载仓库中的 [`index.html`](./index.html)。
2. 用 Microsoft Edge 或 Google Chrome 打开。
3. 将鼠标移到页面顶部，展开会议工具栏；点击左下角的 `+` 打开设置。

页面主体为单个 HTML 文件。界面图标和截图组件已内嵌；联网时可加载额外字体，离线时会使用系统字体。

## 主要功能

| 功能 | 使用方法 |
| --- | --- |
| 会议工具栏 | 鼠标移到顶部展开；按住标题栏空白处拖动位置。会议时间和成员人数可直接点击编辑。 |
| 讲话浮条 | 点击浮条文字修改讲话者，拖动浮条空白处改变位置。 |
| 幻灯片背景 | 点击左下角 `+` 上传图片，或悬停旁边的折叠卡片并点击缩略图切换。右下角箭头可切换到下一张。最多保留 5 张，刷新页面后需重新上传。 |
| 模拟任务栏 | 显示用户提供的应用图标与系统托盘图标；可在设置中修改模拟日期和时间。 |
| 时间倍速 | 按住右下角 `×20` 或 `×60`，任务栏时钟和会议计时同步加速；松开后恢复正常流速。 |
| 截图 | 点击右下角截图按钮，保存从页面顶部到模拟任务栏底边的 PNG，并按 `会议截图-0001.png` 等顺序编号。截图时会议工具栏会保持展开。 |
| 显示比例 | 在 `+` 菜单中选择“调整分辨率（beta测试版）”，等比例调整页面元素。 |

首次截图时，Edge 或 Chrome 会提示选择保存文件夹；选择**桌面**后，本次打开页面期间的后续截图会直接保存到该文件夹。如果浏览器不支持文件夹选择，图片会保存到浏览器设置的默认下载位置。

## 数据与兼容性

- 倍速仅影响页面内的模拟时钟，不影响操作系统时间。
- 会议计时、成员人数、显示比例、工具栏位置和截图编号保存在当前浏览器的本地存储中。
- 上传的背景图片仅在当前页面会话中保留，刷新后需重新选择。
- 建议使用较新的 Microsoft Edge 或 Google Chrome，并在电脑尺寸的浏览器窗口中查看。
